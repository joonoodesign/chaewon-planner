## ☁️ 내 구글 드라이브(Google Drive)로 24시간 DB 관리 & 웹앱 실행하기 (컴퓨터 꺼도 작동 ⭐)

아버님의 구글 드라이브를 이용해서 **프로그램 화면(웹사이트)**과 **데이터베이스(`chaewon_planner_db.json`)**를 동시에 100% 무료로 운영할 수 있도록 세팅해 두었습니다!

### 🚀 딱 1분! 구글 드라이브 24시간 연동 순서

1. **구글 드라이브에 파일 3개 올리기**
   - [내 구글 드라이브(drive.google.com)](https://drive.google.com)를 엽니다.
   - 컴퓨터 `d:\antigravity` 폴더 안에 있는 다음 파일 3개를 마우스로 끌어다 구글 드라이브에 업로드합니다:
     - [index.html](file:///d:/antigravity/index.html)
     - [styles.css](file:///d:/antigravity/styles.css)
     - [app.js](file:///d:/antigravity/app.js)

2. **구글 앱스 스크립트(Apps Script) 붙여넣기**
   - 현재 실행 중인 플래너([http://localhost:8080](http://localhost:8080)) 우측 상단 **`☁️ 동기화`** 버튼 → **`📋 1단계: 구글 드라이브 DB 스크립트 코드 원클릭 복사`** 버튼을 누릅니다. (또는 [google_drive_db.gs](file:///d:/antigravity/google_drive_db.gs) 파일 내용을 복사합니다.)
   - [Google Apps Script (script.google.com)](https://script.google.com)에 접속하여 좌측 상단 **`[+ 새 프로젝트]`**를 클릭합니다.
   - 원래 적혀 있는 `function myFunction() {}`을 지우고 복사한 코드를 붙여넣은 뒤 저장(`Ctrl + S` 또는 상단 디스크 아이콘)합니다.

3. **[웹 앱]으로 배포하고 채원이에게 링크 전달하기**
   - 우측 상단 파란색 **`[배포]`** 버튼 → **`[새 배포]`** 클릭
   - 좌측 톱니바퀴(유형 선택) 클릭 → **`[웹 앱]`** 선택
   - 설정 2가지를 확인합니다:
     - **다음 사용자로 실행**: `나 (본인 구글 이메일)`
     - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** *(※ 매우 중요! 이렇게 해야 채원이가 아이폰/아이패드에서 별도 로그인 창 없이 즉시 접속 및 동기화됩니다)*
   - **`[배포]`** 클릭 → **`[액세스 승인]`** 클릭
   -*(참고: 구글에서 "확인되지 않은 앱" 안내가 뜨면 좌측 하단 `[고급]` → `[프로젝트(안전하지 않음)로 이동]` → `[허용]`을 누르면 됩니다. 본인이 만든 스크립트라 뜨는 정상 안내입니다.)*
   - 완료 화면에 나오는 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다!

## 🎉 이렇게 하면 어떻게 작동하나요?

1. **컴퓨터를 완전히 꺼놓아도 24시간 접속 가능**:
   - 방금 복사한 **`https://script.google.com/macros/s/.../exec`** 링크를 **채원이 카카오톡**으로 보내주면, 채원이가 경북대 캠퍼스나 수학학원 어디서든 아이폰·아이패드·노트북으로 24시간 접속할 수 있습니다!
2. **내 구글 드라이브에 DB 자동 저장**:
   - 채원이가 할 일을 추가하거나 학원 수업 시간을 기록할 때마다 아버님의 구글 드라이브 안에 **`chaewon_planner_db.json`** 파일이 자동으로 생성되고 실시간으로 업데이트됩니다!
3. **집 컴퓨터([http://localhost:8080](http://localhost:8080))와도 완벽 연동**:
   - 집 컴퓨터 화면의 **`☁️ 동기화`** 창에도 해당 URL을 붙여넣고 **[연결 & 즉시 동기화]**를 누르면 집 컴퓨터와 구글 드라이브도 하나로 연결됩니다.
